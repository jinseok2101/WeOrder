# 🛵 WeOrder (같이 시켜요)

이웃들과 함께 배달비를 분담하고 실시간으로 정산 및 배달 상태를 공유하는 공동 배달 플랫폼 서비스입니다.

- **바로가기**: [WeOrder](https://weorder.vercel.app)

---

## 📝 프로젝트 요약 (Project Summary)

WeOrder는 1인 가구의 급증으로 인해 혼자서 부담하기에는 너무 비싸진 배달비 문제와, 1인분 주문 시 쉽게 채우기 어려운 배달 앱의 '최소 주문 금액' 문제를 동시에 해결하기 위해 기획되었습니다.
같은 아파트나 건물 등 가까운 거리에 사는 이웃들이 실시간으로 방을 개설하여 공동으로 주문함으로써 최소 주문 금액을 손쉽게 충족하고, 배달비는 N분의 1로 합리적으로 분담할 수 있는 상생 플랫폼입니다.

---

## 🌟 주요 기능 (Key Features)

1. **실시간 공동 주문 현황 및 배달비 자동 분담 계산**:
   - **실시간 변동성 대응**: 방 멤버의 실시간 참여 및 탈퇴 상태를 웹소켓으로 감지하여, 인원 변경에 따른 **1인당 예상 배달비를 실시간으로 자동 재계산**하여 화면에 피드백합니다.
   - **참여율 독려 UI**: 방의 최소 주문 금액 대비 현재까지 담긴 메뉴 총액의 달성률을 퍼센트(%) 및 애니메이션 바(Progress Bar)로 시각화하여 공동 구매 참여율을 독려합니다.
2. **Socket.io 기반의 양방향 실시간 대화방 (채팅)**:
   - **실시간 소통**: 방 참여자 간 실시간 텍스트 채팅 송수신 기능을 지원하며, React Query의 캐시 동기화를 활용해 실시간 메시지 수신 시 화면이 끊김 없이 부드럽게 렌더링됩니다.
   - **시스템 이벤트 처리**: 새로운 멤버 입장, 기존 멤버 퇴장, 배달 시작 등 주요 방 상태 변동 이벤트 발생 시 채팅창 내에 시스템 공지 메시지(System Message)를 자동 생성하여 사용자가 방의 상태 변화를 직관적으로 파악할 수 있도록 돕습니다.
3. **정산 및 송금 상태의 실시간 소켓 연동 (Settlement)**:
   - **주문 마감 및 정산 요청**: 공동 주문이 성공하여 방장이 배달 주문을 접수한 후, 각 멤버에게 메뉴 합산 금액과 배달비 분담액을 산출한 실시간 정산 요청서를 자동 전송합니다.
   - **간편 송금 연동**: 각 유저의 간편 송금을 위한 토스(Toss) 앱 자동 실행, 방장의 카카오페이 송금 링크 연동, 계좌번호 복사 기능을 제공하여 정산 및 송금의 번거로움을 최소화합니다.
   - **실시간 입금 상태 동기화**: 멤버들의 "송금 완료" 상태와 방장의 "입금 확인" 상태를 Socket.io 이벤트를 통해 전 참가자의 화면에 즉각적으로 실시간 동기화하며, 전원 완료 시 방 상태가 자동으로 `SETTLED`로 전환됩니다.
4. **OS 시스템 알림 및 미확인 알림 배지 (Deep Link)**:
   - **멀티플랫폼 푸시 알림**: 모바일 앱(Expo Push Notifications) 및 PC/웹 브라우저 PWA(Service Worker 및 Web Push API) 환경 모두를 지원하여 백그라운드 환경에서도 실시간 알림을 수신합니다.
   - **스마트 딥링크**: OS 상태바에 도착한 알림(채팅, 정산 요청 등)을 터치/클릭하면 사용자가 앱 내의 알림 보관함으로 이동하지 않고, **해당 방의 채팅방 탭 또는 정산 탭으로 즉시 타겟 페이지 이동**이 이루어집니다.
   - **실시간 알림 배지**: 홈 화면 및 방 상세 상단의 알림 종 아이콘에 미확인 알림 상태를 알려주는 **실시간 빨간 점 배지**를 실시간 소켓 연결 및 캐시 무효화(Query Invalidation)를 활용해 구현하여 실시간으로 갱신합니다.
5. **실시간 배달 도착 예정 알림**:
   - **도착 알림 브로드캐스트**: 배달 음식이 공동 픽업지로 오고 있을 때, 방장이 배달 도착 예정(10분 전, 5분 전, 도착 완료!) 알림 버튼을 제어할 수 있습니다.
   - **타겟 알림 발송**: 방장이 시간 선택 시, 소켓을 통한 실시간 인앱(In-app) 알림창 팝업과 함께 방장을 제외한 파티원 전원의 디바이스 OS에 백그라운드 푸시 알림을 즉각적으로 브로드캐스트합니다.
6. **이웃 매너 평가 및 신뢰 지수 시스템**:
   - **상호 신뢰성 검증**: 공동 배달 및 정산이 마감된 이후(`SETTLED` 상태), 참여한 이웃에 대해 매너 신뢰도 별점 평가(0.5 ~ 5.0점) 및 매너 키워드 태그(약속을 잘 지켜요, 입금이 빨라요 등) 평가를 지원합니다.
   - **신뢰 점수 자동 환산**: 수집된 피드백을 기반으로 사용자의 데이터베이스 내 **Manner Trust Score (신뢰 점수)**가 자동 산출되어 적용되며, 유저 프로필 조회 시 이를 시각화하여 악성 유저 참여를 필터링할 수 있습니다.
7. **GPS 기반 정밀 위치 필터링 및 동네 인증**:
   - **주소 기반 반경 필터링**: 주소 설정 시 네이버 지도 API(Reverse Geocoding)를 통해 사용자가 지정한 지도 중심점의 실제 도로명/지번 주소와 행정동(동네) 정보를 추출하고, 사용자의 현재 활성화된 위치 반경(1km ~ 5km 이내)에 개설된 배달방만 메인 피드에 노출합니다.
   - **법정동 매칭**: 동일한 행정동/법정동 경계에 위치한 배달방 우선 매칭 및 거리순 정렬을 지원하여 오피스텔이나 아파트 단지 등 초근거리 매칭 확률을 높입니다.
