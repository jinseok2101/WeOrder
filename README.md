# 🛵 WeOrder (같이 시켜요)

이웃들과 함께 배달비를 분담하고 실시간으로 정산 및 배달 상태를 공유하는 공동 배달 플랫폼 서비스입니다.

- **바로가기**: [WeOrder](https://weorder.vercel.app) *(※ 모바일 기기로 접속 시 브라우저의 **'홈 화면에 추가'** 기능을 통해 앱스토어 설치 없이 네이티브 앱처럼 즉시 이용하실 수 있습니다.)*
- **개발 구분**: 개인 프로젝트 (1인 개발 - 웹 & 모바일)
- **개발 기간**: 2026.03.23 ~ 2026.06.09

---

## 📝 프로젝트 요약 (Project Summary)

WeOrder는 1인 가구의 급증으로 인해 혼자서 부담하기에는 너무 비싸진 배달비 문제와, 1인분 주문 시 쉽게 채우기 어려운 배달 앱의 '최소 주문 금액' 문제를 동시에 해결하기 위해 기획되었습니다.
같은 아파트나 건물 등 가까운 거리에 사는 이웃들이 실시간으로 방을 개설하여 공동으로 주문함으로써 최소 주문 금액을 손쉽게 충족하고, 배달비는 N분의 1로 합리적으로 분담할 수 있는 상생 플랫폼입니다.

## 🌟 주요 기능 (Key Features)

| 대분류          | 기능                         | 상세 설명                                                                                                                                                                                                                                                                     | 주요 기술                                          |
| :-------------- | :--------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------- |
| **공동 주문**   | **실시간 배달비 분담**       | 방 멤버의 실시간 참여 및 탈퇴 상태를 감지하여 1인당 예상 배달비를 실시간으로 자동 재계산하고, 최소 주문 금액 대비 달성률을 시각화합니다.                                                                                                                                      | Socket.io, Progress Bar UI                         |
| **실시간 채팅** | **양방향 실시간 대화방**     | 참가자 간의 텍스트 채팅 송수신을 지원하고, 새로운 멤버 입장, 기존 멤버 퇴장, 배달 시작 등 주요 방 상태 변경 시 시스템 공지 메시지를 자동 생성합니다.                                                                                                                          | Socket.io, React Query 캐시 동기화                 |
| **정산 & 송금** | **실시간 정산 및 동기화**    | 주문 접수 시 메뉴 금액과 배달비 분담액이 계산된 정산서를 전송하며, 멤버의 송금 완료 및 방장의 입금 확인 상태를 실시간으로 공유하고 전원 완료 시 방을 `SETTLED` 상태로 자동 전환합니다. 또한 토스 앱 실행, 카카오페이 송금 링크 연동, 계좌번호 복사 등 간편 송금을 지원합니다. | Socket.io, Toss App & KakaoPay Link                |
| **푸시 알림**   | **멀티플랫폼 알림 & 딥링크** | 모바일 앱(Expo)과 PC/웹 브라우저(PWA Web Push) 환경에서 백그라운드 실시간 알림을 수신하며, 클릭 시 해당 방의 채팅/정산 탭으로 즉시 이동하고 미확인 알림 상태를 실시간 빨간 점 배지로 표시합니다.                                                                              | Service Worker, Web Push API, Expo Push, Deep Link |
| **배달 상태**   | **배달 도착 예정 알림**      | 방장이 도착 예정 시간(10분 전, 5분 전, 도착 완료!) 알림 버튼을 누르면, 방장을 제외한 파티원 전원에게 인앱 알림창 팝업과 디바이스 OS 백그라운드 푸시 알림을 즉각적으로 발송합니다.                                                                                             | Socket.io, Push Notification API                   |
| **신뢰 평가**   | **이웃 매너 평가 시스템**    | 공동 배달 및 정산 마감 후 참여한 이웃에 대해 매너 신뢰도 별점(0.5 ~ 5.0점) 및 매너 키워드 태그(약속을 잘 지켜요, 입금이 빨라요 등) 평가를 지원하고 Manner Trust Score(신뢰 점수)를 자동 산출합니다.                                                                           | Prisma Transaction, Profile Rating UI              |
| **위치 인증**   | **GPS 기반 위치 필터링**     | 주소 설정 시 네이버 지도 API(Reverse Geocoding)를 통해 실제 행정동/법정동 정보를 추출하고, 지정한 반경(1km ~ 5km 이내) 내 개설된 방을 노출하며 근거리 우선 매칭 및 거리순 정렬을 통해 초근거리 매칭 확률을 높입니다.                                                          | Naver Maps API (Reverse Geocoding)                 |
